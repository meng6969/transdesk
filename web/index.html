我的词典 优先级最高：命中你的词条就不再走内置词库

导入格式：一行一组，源语和译文用逗号 / 制表符 / 竖线 / 管道分隔；有表头时按表头取列（term,translation、ECDICT 的 word,phonetic,translation 会自动跳过音标列）。上方「方向」下拉决定导入方向，脚本对不上的行会自动纠正（例如选中「中 → 英」时，英文行仍按英 → 中收录）。单次最多导入 20000 条。词条只存在这台设备的浏览器里（IndexedDB），不会同步到任何服务器。

它是怎么工作的，以及不适合用在哪

四步，全部在你的浏览器里

  1. 切词：英文按词形与标点切开；日文按汉字／假名段切，再对动词、形容词做活用还原（走って → 歩く、食べて → 食べる）。
  2. 短语优先：先在词典里做最长匹配（take it easy、〜お疲れ様です），命中短语就不会被拆成零散单词，这是离线引擎最重要的质量来源。
  3. 虚词与语序规则：冠词/复数/时态、日文助词（は・が・を・に・で・と・の）、句末语气（か・ね・よ・でしょう）按规则映射成中文的地道表达，而不是硬贴字面。
  4. 成句：按中文语序拼接、清洗标点，并给出逐段对照，你能看到每一块是被哪条规则或哪个词条翻出来的。

请把它用在这些地方（以及不要用在这些地方）

擅长：读英文/日文网页段落、日志与 README、通知与评论、日常短句、看剧截图里的台词——需要“看懂大意”而不是“发表级译文”的场景，以及任何你不想把内容交给服务器的隐私材料。

不擅长：法律、合同、医疗、财务等必须精确的文本；文学与双关；长难嵌套从句。它是词典 + 规则引擎，不是神经网络翻译模型：术语固定、句式常见的文本质量很好，越文学化、越口语化越容易出怪句子。

专有名词、人名、公司名、产品名默认保留原文（离线没有可靠的音译表）；把它们加进“我的词典”就能固定译法，这也是让译文越来越合你口味的正确姿势。

中 → 英 / 中 → 日为短句设计：主谓宾清楚的一两句效果不错，长段落会退化成关键词式译文，说明区不粉饰这一点。

隐私说明

本站是纯静态站点：没有后端接口、没有数据库、没有第三方脚本与统计。文字、图片、你导入的词典都只在浏览器内处理，也不会写入任何网络请求。断网、飞行模式下依旧可用（资源与词库已被本机缓存）。
